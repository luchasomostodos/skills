# Análisis financiero del EL

Motor determinístico para la Dim 02 (Negocio) y la Dim 03 (Capital) de un EL. Lee el modelo financiero seed, el cap table y los SAFE, y calcula unit economics, márgenes, EBITDA frente a deuda, ratio Studio sobre FL, dilución del founder y banderas cuantitativas.

## Contenido

- [SKILL.md](SKILL.md): método, cálculos y salidas.
- [references/](references/): cómo leer el modelo financiero y la calculadora del ratio.
- [CHANGELOG.md](CHANGELOG.md): historial de cambios del skill.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

Su nombre de instalación e invocación es `analisis-financiero-el`.

## Uso

```text
Usa $analisis-financiero-el para leer el modelo financiero de este caso.
Usa $analisis-financiero-el para calcular la dilución del founder con esta ronda.
```

Los datos de ejemplo de este skill están anonimizados: los nombres de personas y empresas son ficticios y los montos están alterados. Consultar la [guía de la carpeta](../README.md) y la [guía principal](../../README.md) para instalarlo.
