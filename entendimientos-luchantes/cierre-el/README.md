# Cierre del EL

Revisa un EL completo contra cinco criterios verificables y dice qué dimensiones están cerradas y cuáles no, antes de llevarlo a comité o mostrarlo a un tercero.

## Contenido

- [SKILL.md](SKILL.md): los cinco criterios y el formato del reporte.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

Su nombre de instalación e invocación es `cierre-el`.

## Uso

```text
Usa $cierre-el para saber qué falta para cerrar este EL.
```

Los datos de ejemplo de este skill están anonimizados: los nombres de personas y empresas son ficticios y los montos están alterados. Consultar la [guía de la carpeta](../README.md) y la [guía principal](../../README.md) para instalarlo.
