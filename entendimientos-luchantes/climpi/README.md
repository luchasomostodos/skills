# Climpi

Audita el razonamiento de un EL en borrador con Fooled by Randomness de Taleb: dónde la convicción de LUCHA se apoya en azar que parece habilidad en vez de evidencia. El sujeto auditado es LUCHA, no el founder.

## Contenido

- [SKILL.md](SKILL.md): preguntas de auditoría y formato de salida.
- [references/](references/): marco completo.
- [examples/](examples/): salida de ejemplo.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

Su nombre de instalación e invocación es `climpi`.

## Uso

```text
Usa $climpi para revisar dónde nos estamos engañando en este EL.
```

Los datos de ejemplo de este skill están anonimizados: los nombres de personas y empresas son ficticios y los montos están alterados. Consultar la [guía de la carpeta](../README.md) y la [guía principal](../../README.md) para instalarlo.
