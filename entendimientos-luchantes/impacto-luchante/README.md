# Impacto Luchante

Arma la ficha de impacto ABC de un caso para el Gate de Impacto, propone el puntaje de la Dim 05 y deja listo el modelo de impacto para el founder.

## Contenido

- [SKILL.md](SKILL.md): cómo se arma la ficha, el puntaje y el modelo de impacto.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

Su nombre de instalación e invocación es `impacto-luchante`.

## Uso

```text
Usa $impacto-luchante para armar la ficha de impacto de este caso.
Usa $impacto-luchante para decir si el caso es tipo C.
```

Los datos de ejemplo de este skill están anonimizados: los nombres de personas y empresas son ficticios y los montos están alterados. Consultar la [guía de la carpeta](../README.md) y la [guía principal](../../README.md) para instalarlo.
