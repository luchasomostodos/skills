# Marca LUCHA para tableros

Aplica el sistema de marca de LUCHA Impact Studio al producir artifacts, dashboards, tableros, one-pagers, HTML o componentes React internos: neutros cálidos en modo claro y oscuro, paleta, tipografía, semáforo, tokens, componentes y dos UI kits (Mapas y Portafolio).

## Contenido

- [SKILL.md](SKILL.md): reglas de marca y checklist.
- [assets/](assets/): tokens CSS y página de muestra.
- [references/](references/): componentes, tokens originales, UI kits de Mapas y Portafolio, y handoff de Mapas.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

Su nombre de instalación e invocación es `lucha-brand`.

Para webs y landing pages de Lucha se usa [identidad-lucha](../../identidad-lucha/README.md). Este skill es para tableros, paneles y artifacts internos.

## Uso

```text
Usa $lucha-brand para armar este tablero del portafolio.
```

Los datos de ejemplo de este skill están anonimizados: los nombres de personas y empresas son ficticios y los montos están alterados. Consultar la [guía de la carpeta](../README.md) y la [guía principal](../../README.md) para instalarlo.
