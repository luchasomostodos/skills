Hairline-bordered, softly-shadowed surface — the container for every panel in the equipo app.

```jsx
<Card>
  <CardHeader>
    <CardTitle>Fondo Luchante</CardTitle>
    <CardDescription>Métricas trimestrales del fondo</CardDescription>
  </CardHeader>
  <CardContent>…</CardContent>
</Card>
```

Sub-parts: `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`. Override radius/padding via `style` for hero treatments.
