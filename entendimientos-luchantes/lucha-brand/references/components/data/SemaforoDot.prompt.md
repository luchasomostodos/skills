The control-tower status dot — verde / amarillo / rojo / gris with an optional label. The signature indicator across every equipo view.

```jsx
<SemaforoDot estado="verde" />
<SemaforoDot estado="rojo" showLabel={false} size={8} />
```

`estado={null}` renders an em-dash. Labels: Cumple · Por cumplir · No cumple · Sin datos.
