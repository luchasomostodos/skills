# Saboteadores

Interpreta el perfil de saboteadores y el PQ de un founder con el marco Positive Intelligence de Shirzad Chamine. Alimenta la Dim 08 (Bienestar y Liderazgo) del EL.

## Contenido

- [SKILL.md](SKILL.md): método y formato de salida.
- [references/](references/): marco Positive Intelligence.
- [examples/](examples/): salida de ejemplo.
- [evals/](evals/): casos de prueba con datos ficticios.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

Su nombre de instalación e invocación es `saboteadores`.

## Uso

```text
Usa $saboteadores para interpretar el test de saboteadores de este founder.
```

Los datos de ejemplo de este skill están anonimizados: los nombres de personas y empresas son ficticios y los montos están alterados. Consultar la [guía de la carpeta](../README.md) y la [guía principal](../../README.md) para instalarlo.
