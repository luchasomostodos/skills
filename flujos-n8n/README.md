# Flujos n8n de Lucha

Skill para crear, modificar y revisar workflows en el n8n de Lucha con un mismo estándar: configuración, nombres de flujos y nodos, notas y manejo de errores. Con él, cualquier persona del equipo entiende qué hace un flujo al mirarlo y Javo puede monitorearlos todos.

## Contenido

- [SKILL.md](SKILL.md): modos de trabajo, reglas y comprobación final.
- [Referencias](references/README.md): configuración exacta, nombres y notas con ejemplos, y revisión.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

Su nombre de instalación e invocación es `flujos-n8n`.

## Uso

```text
Usa $flujos-n8n para crear un flujo que avise en Slack cuando llegue un formulario.
Usa $flujos-n8n para revisar si los flujos de Chief cumplen el estándar.
```

El modo revisión solo reporta. Las correcciones se hacen cuando se piden.

El estándar se aplicó a los flujos publicados el 5 de noviembre de 2026. Consultar la [guía principal](../README.md) para instalarlo.
