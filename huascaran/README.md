# Huascarán

Carpeta de los skills propios del producto Huascarán. Su nombre de directorio se escribe `huascaran` sin tilde para facilitar el uso en rutas y comandos; los textos visibles conservan Huascarán.

## Skills disponibles

| Skill | Para qué sirve |
| --- | --- |
| [interfaz-huascaran](interfaz-huascaran/README.md) | Mantener restricciones de navegación, filtros, tarjetas, sprints, misiones, reporte diario, agentes, memos y notificaciones |

La identidad general de Lucha se mantiene en [identidad-lucha](../identidad-lucha/README.md). Aquí se guardan las decisiones particulares de Huascarán.

## Uso

```text
Usa $interfaz-huascaran para revisar la nueva pantalla de Huascarán.
```

La [guía principal](../README.md) explica cómo instalar la identidad compartida y los skills de este proyecto. Un futuro procedimiento específico puede añadirse como otro skill dentro de esta carpeta, con nombre único y README propio.
