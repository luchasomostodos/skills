# Interfaz de Huascarán

Skill para crear, modificar o revisar pantallas de Huascarán conservando las decisiones tomadas durante su desarrollo.

## Contenido

- [SKILL.md](SKILL.md): alcance, invariantes y forma de consultar las reglas.
- [Referencias](references/README.md): recopilación detallada de restricciones, medidas y cambios posteriores.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

## Uso

```text
Usa $interfaz-huascaran para modificar los filtros y el detalle de una misión.
```

La referencia se recopiló el 4 de noviembre de 2026. Separa decisiones confirmadas, medidas observadas en el código y preguntas que aún no se habían cerrado. Los pedidos nuevos y las instrucciones actuales del proyecto pueden modificarla.

Este skill no ejecuta agentes, cambia permisos ni publica memos por sí solo. Está enfocado en los lineamientos del producto.
