# Lineamientos de Huascarán

[lineamientos.md](lineamientos.md) reúne las restricciones recopiladas del historial de desarrollo y de la documentación del producto.

Incluye escritura, bordes, identidad, medidas, navegación, filtros, sprints, misiones, reporte, agentes, memos, notificaciones, login y restricciones de datos que la interfaz debe respetar.

La sección final identifica contradicciones resueltas y pedidos pendientes a la fecha de recopilación. Consultarla antes de tratar una decisión histórica como requisito vigente. Los enlaces de origen apuntan al repositorio de Huascarán, sin depender de rutas locales del equipo.
