# Identidad de Lucha

Skill compartido para diseñar y modificar webs de Lucha con una identidad coherente: logos auténticos, paleta, tipografía, escritura y componentes compactos.

## Contenido

- [SKILL.md](SKILL.md): instrucciones que lee el agente.
- [Referencias](references/README.md): identidad documentada y criterios de interfaz.
- [Activos](assets/README.md): logos, favicon y variables CSS.
- [Configuración](agents/README.md): nombre y descripción que aparecen en el selector de skills.

Su nombre de instalación e invocación es `identidad-lucha`.

## Uso

```text
Usa $identidad-lucha para diseñar esta web de Lucha.
```

Se aplica a interfaces identificadas como productos de Lucha. Las reglas funcionales de Huascarán se encuentran en su propia carpeta y no se trasladan automáticamente a otras webs.

Consultar la [guía principal](../README.md) para instalarlo.
