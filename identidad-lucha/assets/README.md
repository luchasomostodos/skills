# Activos de identidad

| Archivo | Uso |
| --- | --- |
| `lucha-logo-blue.png` | Logo horizontal azul para fondos claros |
| `lucha-logo-white.png` | Logo horizontal blanco para fondos oscuros o azules |
| `lucha-favicon.png` | Favicon registrado en Huascarán |
| [tokens.css](tokens.css) | Variables de color y medidas de partida para un proyecto nuevo |

Los archivos de imagen son copias exactas de los activos de marca que utiliza Huascarán. Conservar sus proporciones y no sustituirlos por dibujos aproximados.

Los tokens no modifican componentes ni la página por sí solos. Sus valores de interfaz se adaptan al proyecto. Las fuentes y el alcance de marca están en [Identidad](../references/identidad.md).
