# Referencias de identidad

- [identidad.md](identidad.md): fuentes de marca, paleta, logos, tipografía y voz. Distingue identidad oficial documentada de preferencias de interfaz del usuario.
- [interfaces.md](interfaces.md): densidad, medidas de referencia, estados, navegación y accesibilidad para componentes web.

Estos archivos aportan detalles al [skill de identidad](../SKILL.md); se consultan según el componente o trabajo solicitado. Las medidas de referencia no obligan a que todas las webs tengan la misma composición.
