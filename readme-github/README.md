# README de GitHub de Lucha

Skill para crear, actualizar y revisar el README de cualquier repositorio de Lucha. El resultado es un README en lenguaje simple y sin términos técnicos, con el mismo orden que el de [Coco](https://github.com/luchasomostodos/coco): qué hace el proyecto, en qué estado está y qué falta.

## Contenido

- [SKILL.md](SKILL.md): modos de trabajo, estructura, cómo se escribe y comprobación final.
- [Referencias](references/README.md): las partes del README, el cambio de palabras técnicas por palabras simples y cómo revisar.
- [Configuración](agents/README.md): nombre y descripción visibles del skill.

Su nombre de instalación e invocación es `readme-github`.

## Uso

```text
Usa $readme-github para escribir el README de este repositorio.
Usa $readme-github para poner al día el README de Chief con lo que hace hoy.
Usa $readme-github para revisar si el README de Coco se entiende sin saber programar.
```

Cuando el repositorio y lo que corre en producción no coinciden, el README cuenta lo que corre. Consultar la [guía principal](../README.md) para instalarlo.
